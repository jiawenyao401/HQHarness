2. 在客户端独立验收会话中，仅调用 `mcp__huaqing_wps__wps_use` 的 `status`、`documents`、`inspect`、`writer_replace`、`save` 和再次 `inspect`；逐项确认文档列表、读取、修改及保存授权。

4. 独立检查 WPS 窗口中的替换结果，关闭该临时文档，再从 WPS 最近文档重新打开，确认修改后的文字仍然存在。随后关闭临时文档，保留文件供用户复核。
